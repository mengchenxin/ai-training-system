# 新电脑安装说明（照着做就行）

> 目标：在一台全新的 Windows 电脑上，把毕设跑起来。
> 一共装 4 个东西，大约 20 分钟。装完把项目文件夹复制过去，双击就能用。

---

## 一、先搞清楚要装什么

| 序号 | 软件 | 干什么用 | 必须吗 | 大小 |
|---|---|---|---|---|
| 1 | JDK 21（Java 运行环境） | 运行后端 | **必须** | 约 200 MB 安装包 |
| 2 | MySQL 8.0（数据库） | 存数据 | **必须** | 约 300 MB 安装包 |
| 3 | Node.js 22（前端运行环境） | 跑网页界面 | **必须** | 约 30 MB |
| 4 | Maven | 重新编译 Java 代码 | **不需要**（见下方说明） | — |

### 关于 Maven：新电脑不用装

因为项目里已经打好了一个 jar 包（`server\target\ai-training-server-1.0.0.jar`，41 MB），
直接运行它就行，不需要重新编译。

**只有一种情况需要 Maven**：你要改 Java 代码，然后重新生成 jar。
那时候装个 IDEA 就行，IDEA 会自己处理编译，不用单独装 Maven。

## 二、装 JDK 21（第 1 个）

### 下载

推荐用 Eclipse Temurin（免费、开源，不用注册账号）：

```
https://adoptium.net/temurin/releases/?version=21&os=windows&arch=x64&package=jdk
```

选 **Windows / x64 / JDK / 21**，下载 `.msi` 安装包。

国内下载慢的话用清华镜像：

```
https://mirrors.tuna.tsinghua.edu.cn/Adoptium/21/jdk/x64/windows/
```

文件名类似 `OpenJDK21U-jdk_x64_windows_hotspot_21.0.x_x.msi`。

### 安装时勾什么（重要）

双击 msi，一路下一步，到「Custom Setup」这一步时，把下面几项改成 **Will be installed on local hard drive**（就是下拉菜单里选它）：

- **Set JAVA_HOME variable** ← 一定要勾，很多人就是漏了这个
- **Add to PATH** ← 一定要勾
- JavaSoft (Oracle) registry keys（可选，勾了也没关系）

然后一路 Next 到底，点 Install。

### 装完验证

按 `Win + R`，输入 `cmd`，回车，在黑窗口里输入：

```cmd
java -version
```

看到类似这样的输出就成功了：

```
openjdk version "21.0.11" 2026-xx-xx
OpenJDK Runtime Environment Temurin-21.0.11+9 (build 21.0.11+9)
```

**关键点：版本号必须是 21 开头。** 如果是 17 或 8，说明装错了，或者电脑上有旧版本 Java 优先被找到了。

### 如果显示「不是内部或外部命令」

说明 PATH 没配上。手动配：

1. 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量
2. 在「系统变量」里点「新建」：
   - 变量名：`JAVA_HOME`
   - 变量值：你的 JDK 安装路径，例如 `C:\Program Files\Eclipse Adoptium\jdk-21.0.11.9-hotspot`
3. 找到「系统变量」里的 `Path`，双击，点「新建」，加一行：
   ```
   %JAVA_HOME%\bin
   ```
4. 一路点确定，然后**关掉 cmd 重新打开**（环境变量要重开窗口才生效）

## 三、装 MySQL 8.0（第 2 个）

### 下载

```
https://dev.mysql.com/downloads/installer/
```

选 **Windows (x86, 32-bit), MSI Installer** 里体积大的那个（约 300 MB，带 Installer 全套）。

> 页面上会问你要不要注册 Oracle 账号，**不用注册**，点下面那行小字
> 「No thanks, just start my download」直接下载。

国内镜像（如果官网慢）：

```
https://mirrors.huaweicloud.com/mysql/Downloads/MySQL-8.0/
```

### 安装步骤

1. 双击安装包，选 **Custom**（自定义），Next
2. 左边展开，只选 **MySQL Server 8.0.x**，点箭头加到右边，Next
3. 点 **Execute** 开始安装，等它装完，Next
4. **Type and Networking**：保持默认 `Development Computer`，端口保持 **3306**，Next
5. **Authentication Method**：选第一项 `Use Strong Password Encryption`，Next
6. **Accounts and Roles**：设置 root 密码

> **这一步最重要：把密码记下来！**
> 后面要在项目配置文件里填这个密码，忘了就得重装数据库。
> 建议用纯数字字母，别用特殊符号，例如 `MyPass2026`。

7. **Windows Service**：保持勾选 `Configure MySQL Server as a Windows Service`，
   服务名默认 `MySQL80`，勾上 `Start the MySQL Server at System Startup`（开机自动启动）
8. 一路 Execute → Finish

### 装完验证

MySQL 装好后会自动作为服务运行。黑窗口里输入：

```cmd
netstat -ano | findstr :3306
```

能看到一行带 `LISTENING` 的输出，就说明数据库在跑了。

> 如果提示 `mysql` 不是内部命令，那是因为 MySQL 的 bin 目录没加到 PATH。
> **不影响使用**，后面导入数据时我们会用完整路径。

## 四、装 Node.js 22（第 3 个）

### 下载

```
https://nodejs.org/zh-cn/download
```

选 **LTS 版本（22.x）** 的 Windows 安装包（`.msi`，64-bit）。

国内镜像：

```
https://npmmirror.com/mirrors/node/
```

### 安装

双击 msi，一路 Next，**不需要改任何选项**（安装包会自动加到 PATH）。

到「Tools for Native Modules」那一页时，**不用勾**（项目没有需要编译的依赖）。

### 装完验证

**关掉所有 cmd 窗口再重新打开**，输入：

```cmd
node -v
npm -v
```

应该看到 `v22.x.x` 和 `10.x.x` 这样的版本号。

> **为什么必须 22 以上**：项目的 `web/package.json` 里写了要求
> `Node 20.19+ 或 22.12+`，装 18 或更老的版本，前端会直接装不上依赖。
> 装 22 LTS 最省事。

## 五、环境变量总结（要不要配）

| 软件 | 要配环境变量吗 | 怎么配 |
|---|---|---|
| JDK 21 | **要**（JAVA_HOME + PATH） | 安装时勾选就自动配好了；没勾就照第二节手动加 |
| Node.js | 不用管 | 安装包自动配 |
| MySQL | 不用配 | 装成服务后开机自动运行 |
| Maven | 不用装 | 用 jar 包直接跑 |

装完**一定要关掉所有命令行窗口重新打开**，否则新配的环境变量不生效——这是最容易踩的坑。

## 六、把项目放过去并跑起来

### 第 1 步：复制文件夹

把 `bi` 整个文件夹复制到新电脑，**建议放纯英文路径**，例如：

```
D:\ai-training-bi\
```

> 复制前，先删掉这三个东西（不然复制会卡很久，而且没用）：
> - `work\app\web\node_modules`（几百 MB，新电脑要重装）
> - `work\app\web\.backup-dist-*` 和 `.backup-src-*`（旧备份）
> - `work\app\web\dist`（旧构建产物）

### 第 2 步：先跑一次环境自检

双击项目根目录下的 **`check-env.bat`**（在 `work\app` 里）。

它会检查 Java、Node、MySQL、端口、jar 包是否齐全，哪项有问题会标出来。

### 第 3 步：建数据库并导入数据

打开 cmd，**先进入项目的 sql 目录**：

```cmd
cd /d "D:\ai-training-bi\work\app\server\sql"
```

然后依次执行（把 `你的密码` 换成第三步设置的 root 密码）：

```cmd
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p你的密码 -e "CREATE DATABASE ai_training DEFAULT CHARACTER SET utf8mb4;"
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p你的密码 ai_training < 01-schema.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p你的密码 ai_training < 02-seed.sql
```

验证是否成功：

```cmd
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p你的密码 ai_training -e "SHOW TABLES;"
```

应该列出 **25 张表**。

> 如果 MySQL 装在了别的磁盘或目录，把上面的路径换成你自己的。
> 不知道装哪了？打开「服务」看 MySQL80 的属性，里面有可执行文件路径。

### 第 4 步：改数据库密码

用记事本打开：

```
D:\ai-training-bi\work\app\server\src\main\resources\application.yml
```

找到 `password:` 那一行，把后面的值改成你在第三步设置的 root 密码，保存。

> 这个文件是后端的配置文件，密码不对后端就启动不了，报 `Access denied`。

### 第 5 步：装前端依赖

打开 cmd：

```cmd
cd /d "D:\ai-training-bi\work\app\web"
npm install
```

等它跑完（第一次约 2-5 分钟，取决于网速）。

> 如果卡住不动或者报错，换成国内源再试：
> ```cmd
> npm config set registry https://registry.npmmirror.com
> npm install
> ```

### 第 6 步：启动

一共要开 **三个窗口**，顺序不能乱：

**窗口 1 — 数据库**：MySQL 已经作为服务开机自启，不需要额外开窗口。
如果不确定，双击 `start-mysql.bat`（注意：这个脚本里写的是我原来的路径，新电脑上会报错，所以**跳过它**，直接确认 `MySQL80` 服务在运行即可）。

**窗口 2 — 后端**：

```cmd
cd /d "D:\ai-training-bi\work\app\server"
java -jar target\ai-training-server-1.0.0.jar --server.port=8000
```

看到下面两行就成功了：

```
Tomcat started on port 8000 (http)
Started AiTrainingApplication in X seconds
```

**窗口 3 — 前端**：

```cmd
cd /d "D:\ai-training-bi\work\app\web"
npm run dev
```

看到 `Local: http://localhost:3000` 就好了。

### 第 7 步：打开浏览器

```
http://localhost:3000
```

用 `admin` / `123456` 登录，能看到工作台上的「培训计划 2 个、完成率 53.77%」就说明全部正常。

## 七、出问题看这里

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击 bat 一闪就没 | 找不到 java，或者数据库没起 | 先跑 `check-env.bat` 看哪项标红 |
| `java` 不是内部命令 | JDK 没配 PATH | 看第二节末尾的手动配法，配完重开窗口 |
| `Access denied for user 'root'` | 密码和配置文件不一致 | 改 `application.yml` 里的 password |
| `Unknown database 'ai_training'` | 没建库 | 回到第 3 步重新导入 |
| `Port 8000 was already in use` | 8000 被别的程序占了 | 换端口启动 `--server.port=8001`，同时改 `web\vite.config.ts` 里的 `target` |
| `npm install` 报错 | 网络问题或 Node 版本太低 | 换国内源；确认 `node -v` 是 22 以上 |
| 页面能打开但数据全空 | 后端没起，或者数据库是空的 | 看后端那个窗口有没有报错 |
| 登录提示密码错误 | 数据库导的是空库 | 确认 `02-seed.sql` 导入成功 |
