## 三、发现的问题

### 3.1 指标页的结论与页面数据相反（已修）

`/ai/metrics` 底部原写「纯大模型组的『平均幻觉课程』就是约束必要性的量化证据」，
但同页表格显示：

| 生成模式 | 平均幻觉课程 |
|---|---|
| 纯规则 | 0 |
| 规则+大模型混合 | 0.98 |
| 纯大模型 | 0.07 |

**纯大模型的幻觉数比混合模式低**，那句话等于自己打自己。

根因是两组口径不同：

- HYBRID 走 `validate(root, ruleCourses)` 严格校验，课程超出候选集即整份失败降级，成功路径 `hallucinationCount` 写死 0；
- LLM_ONLY 走 `validateLenient(root, catalog)` 宽松校验，按「课程库中是否存在」统计。

两个数字不同源，不能相减比大小。已把文案改为口径说明，并明确
「约束的价值在于保证课程可选、学时可控，而不是降低幻觉数」。

> 这条与三方讨论里的结论一致：论文口径应写「保预算与可执行」，不要写「防幻觉」。

### 3.2 考试成绩有 2 条空作答记录（待处理）

管理员账号在 2026-10-25 留下「前测/后测 0 分、学员作答为空、未通过」两条记录。
属于测试残留，答辩演示时容易被动。建议清理这两条（不动其他数据）。

### 3.3 效果诊断页为空（待处理）

页面提示「暂无诊断记录」。该模块要求「培训前后差距对比形成效果诊断」，
但没有考试数据就无法产生诊断记录。演示时点开是空表，属展示风险而非功能缺陷。

### 3.4 试卷只有 2 份且同属一人（待处理）

`前测冯桂英` / `后测冯桂英`，其余员工无试卷。数据单薄，组卷功能的展示面不够。

## 四、环境备注（下次巡检直接照此跑）

`npm run dev` 在本机**不可用**：vite 优化器提交缓存时删除临时目录
（53 个文件）触发沙箱 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`，进程直接崩溃。
规避方式是用生产构建产物：

```bash
npx vite build --outDir dist-check
npx vite preview --outDir dist-check --port 3000
```

`vite preview` 会沿用 `server.proxy`，`/api` 正常转发到 8000。

另外，`agent-browser` 的所有命令必须先清空代理环境变量，否则它自己访问
`127.0.0.1` 也会被代理劫持，表现为 CDP 连接失败、`open` 卡死：

```bash
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy
```
